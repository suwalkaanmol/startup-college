1. Right-click placemate.zip > Extract All (do not run it from inside the zip).
2. Open the extracted folder and double-click START-PLACEMATE.bat.
3. First time only: it installs, then asks for your Neon DATABASE_URL once. Paste it and press Enter.
4. The browser opens at http://localhost:4000. Keep the black window open while you use the app.
Next time: just double-click START-PLACEMATE.bat.
To update later: extract the new zip, then copy the old server\.env into the new server folder once (or paste the URL again).
